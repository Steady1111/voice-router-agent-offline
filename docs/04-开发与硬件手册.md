## 一、逻辑分层

```
L1 表现层     浏览器 HTML/CSS/JS 控制台（无登录 v1）
L2 应用层     FastAPI · WebCommandService · DeviceManager · 监控
L3 语音引擎   KWS → 采集窗 → ASR → NLU → 规则/兜底（量产 ASR 子进程）
L4 设备抽象   风扇/LED/继电器 · ubus · ESP32Bridge
L5a 预研执行  ESP32-S3：采音 + PWM + 显示
L5b 量产执行  OpenWrt：ALSA · DAC · GPIO
```

### 技术栈

| 层级 | 语言 / 框架 | 位置 |
|------|-------------|------|
| 语音服务 | Python 3.8+ | `voice_router_lite/` |
| Web | FastAPI + Uvicorn | `voice_router_lite/web/` |
| 前端 | 原生 HTML/CSS/JS | `voice_router_lite/web/static/` |
| 固件 | C++ Arduino / ESP-IDF | `firmware/` |
| NLU 训练 | PyTorch → ONNX | 开发机 |
| 量产 OS | OpenWrt + procd | `deploy/openwrt/` |

| 能力 | 引擎 | 体积约 |
|------|------|--------|
| KWS | sherpa-onnx | ~5MB |
| ASR | Zipformer | ~25MB |
| NLU | CNN+LSTM（可 INT8） | 11MB / 3MB |
| TTS | 预录 WAV | 磁盘 <5MB |
| VAD/降噪 | WebRTC + 频谱门 | 可忽略 |

**不采用：** LLM、Whisper、Paraformer、云 API。

### 运行形态

| 形态 | 命令 | 场景 |
|------|------|------|
| 预研 Web | `python3 -m voice_router_lite web` | Mac + ESP32 |
| 量产 Daemon | `python3 -m voice_router_lite router` | OpenWrt |
| 量产 Web | 同上 web，独立 procd | 监控 / 配套页 |

### 包职责（摘要）

| 包 | 职责 |
|----|------|
| `web/` | HTTP/WS、静态页、浏览器/ESP32 双角色 |
| `kws` `asr` `nlu` `tts` | 引擎封装 |
| `audio/` | 采集、VAD、播放 |
| `device/` | 意图 → 动作 |
| `hardware/` | ESP32 桥 |
| `router/` | daemon、ASR 子进程、调度 |
| `platform/` | ubus、cgroups |
| `pipeline.py` | 非 Web 统一管道 |

前端只做展示与调试输入；**全部 AI 在服务端**；固件只做 IO。

### 端到端（预研控风扇）

```
说话 → INMP441 → ESP32 I2S → WS PCM
  → 服务端音量/KWS 唤醒 → ASR → NLU → DeviceManager
  → ESP32 fan 命令 → PWM / 灯 / 数码管
  → 浏览器展示 + 可选网页女声
```

量产：ALSA 直连、KWS 主唤醒、路由走 ubus、Web 与 daemon 分进程。

## 二、硬件清单与接线

> ESP32-S3 仅预研；量产麦走路由器 USB-I2S。

### 配置总览

| 组件 | 引脚/配置 | 说明 |
|------|-----------|------|
| ESP32-S3 | — | 预研主控 |
| BOOT | GPIO 0 | 按住录音（固件侧） |
| 外部 LED | GPIO 7（串电阻） | 录音指示 |
| RGB | GPIO 48 | WiFi 状态 |
| 四位数码管 | GPIO 10–21 | 计时 / 转速 / 待机 |
| TB6612 + 风扇 | GPIO 8 开关 + GPIO 9 PWM | 执行端 |
| INMP441 | GPIO 4/5/6 I2S | 采音 |

### INMP441

| 模块脚 | ESP32 | 说明 |
|--------|-------|------|
| VDD | 3V3 | |
| GND | GND | |
| SCK | GPIO 4 | BCLK |
| WS | GPIO 5 | LRCLK |
| SD | GPIO 6 | DIN |
| L/R | GND | 左声道 |

### TB6612 + 风扇

| 脚 | 接法 |
|----|------|
| VM | **独立 5V 电源**（勿与 ESP32 USB 共供电） |
| VCC | 3V3 |
| GND | 与 ESP32 **共地** |
| STBY | 3V3 |
| PWMA | GPIO 9 |
| AIN1 | GPIO 8 |
| AIN2 | GND |
| AO1/AO2 | 电机 |

共电易导致电压跌落复位。量产可用继电器做开关。

### 数码管 / LED

段选与位选见固件配置；段脚串约 470Ω。显示约定：录音显示秒数，风扇开显示 PWM，空闲 `----`。

### 配件

预研常用：电源模块、面包板、杜邦线、TB6612、130 电机/风扇叶、LED、电阻、四位数码管等。未接入的套件件可忽略。

## 三、ESP32 配置与烧录

固件内配置（示例，**请按本机热点修改**）：

| 项 | 说明 |
|----|------|
| WiFi SSID / 密码 | 与 Mac 同网 |
| HUB_HOST | Mac 在该热点下的 IP |
| 烧录波特率 | 可降至 115200 提高稳定性 |

进入下载模式：按住 BOOT → 点 RST → 松 RST → 松 BOOT。

```bash
cd firmware && pio run -t upload
```

详见 [firmware/README.zh-CN](../firmware/README.zh-CN.md)。

## 五、FAQ

| 问题 | 处理 |
|------|------|
| 设备不识别 | 换线/驱动；BOOT 再插 |
| 烧录 `device disconnected` | 关掉串口监视 |
| WiFi 找不到 AP | 核对 SSID；兼容模式 |
| RGB 红灯（WS 不通） | 查防火墙与 HUB_HOST |
| 风扇转一下停 | 电机独立供电并共地 |
| 数码管闪 | 检查扫描时序 |
