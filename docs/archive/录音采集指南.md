# 录音 / 采集指南

> 对应 OpenSpec 基线：`2026-06-26-five-optimizations`  
> 详见 [openspec/2026-06-26-five-optimizations/design.md](./openspec/2026-06-26-five-optimizations/design.md) §2.5

项目里有 **三条不同的「录音」线**，用途不同，不要混在一起。

| 线 | 目录 | 训练模型？ | v1 优先级 |
|----|------|------------|-----------|
| **指令采集** | `asr_debug/` | 间接 → NLU 误听文本 | **高（推荐先做）** |
| **唤醒词样本** | `kws_samples/` | 否，仅 KWS 评估 | 中（测 B 线时再做） |
| **TTS 播报** | `audio_clips/` | 否，仅播放听感 | 低（量产前可再做） |

## 一、指令采集（优先，不用坐着录词表）

### 做什么

演示时对着 ESP32 **正常说指令**，系统自动保存每次指令的 WAV + 识别结果，用于分析误识别、补 NLU 规则和再训。

**不重训 ASR（Zipformer）**，只服务 NLU / 规则表。

### 怎么开

```bash
cd /path/to/voice-router-agent-offline

VOICE_ROUTER_SAVE_ASR_WAV=1 \
VOICE_ROUTER_ASR_DEBUG_DIR=./asr_debug \
VOICE_ROUTER_ENERGY_WAKE=1 \
python3 -m voice_router_lite web
```

### 建议说的内容（多试几遍）

| 类别 | 说法示例 | 建议次数 |
|------|----------|----------|
| 开风扇 | 打开风扇、开风扇、开一下风扇 | 各 3～5 次 |
| 关风扇 | 关闭风扇、关风扇、关掉风扇 | 各 3～5 次 |
| 调档 | 风扇调到二档、调大一点、调小一点、微风、全速 | 各 2～3 次 |
| 噪声场景 | **风扇转着**时说「关闭风扇」「关风扇」 | 5 次 |
| 负样本 | 日常闲聊、与风扇/路由无关的短句 | 5～10 次 |
| 路由器（可选） | 重启路由器、WiFi 密码多少、打开访客网络 | 各 2～3 次 |

不必背固定台词，自然说法更好；关键是覆盖 **开 / 关 / 调档 / 误识别 / 噪声** 几种场景。

### 产出位置

```
asr_debug/
├── cmd_20260626_120000_123456.wav
├── cmd_20260626_120000_123456.json   # 含 raw_asr、command、wake_source 等
└── ...
```

### 查看报告

```bash
python3 tools/collect_asr_samples.py --dir ./asr_debug
python3 tools/collect_asr_samples.py --dir ./asr_debug --out ./asr_debug/report.csv
```

### 样本量目标

| 阶段 | 数量 | 用途 |
|------|------|------|
| 可先开始分析 | ≥ 20 条 | 看成功率、补规则 |
| NLU 再训（任务 2A） | ≥ 50 条 | `tools/build_misheard_training.py` |

```bash
python3 tools/build_misheard_training.py --dir ./asr_debug
```

## 二、唤醒词样本（KWS B 线，可选）

### 做什么

录「小T小T」正/负样本，用 `tools/eval_kws_samples.py` 测唤醒命中率、调 `keywords.txt` 阈值。

**不重训 sherpa KWS 大模型。**

### 什么时候需要

- 要验收 **B 线 KWS**（好麦 / 未来路由器 USB 麦）时
- 预研 A 线（能量唤醒 + ESP32 烂麦）**不依赖**这批样本

### 目录结构

```
kws_samples/
├── README.md
├── positive/          # 正样本
│   ├── xiaot_01.wav
│   └── ...
└── negative/          # 负样本
    ├── noise_01.wav
    └── ...
```

### 录制规范

| 项 | 要求 |
|----|------|
| 格式 | 16 kHz、mono、16-bit PCM WAV |
| 设备 | **Mac 内置麦 / USB 好麦**（不要用 ESP32 INMP441） |
| 正样本 | 清晰说「**小T小T**」，每条 1～2 秒，可说 1～2 遍 |
| 负样本 | 环境噪声、日常说话、易误触语句，每条 2～5 秒 |

### 建议数量

| 类型 | 数量 | 通过线（AC-3b） |
|------|------|-----------------|
| 正样本 `positive/` | **20 条** | ≥ 14/20 唤醒成功 |
| 负样本 `negative/` | **10 条** | ≤ 2/10 误唤醒 |

### 评估命令

```bash
# 终端 1：关能量唤醒，单独测 KWS
VOICE_ROUTER_ENERGY_WAKE=0 python3 -m voice_router_lite web

# 终端 2：跑评估
python3 tools/eval_kws_samples.py --root kws_samples
```

### 要录的「词」

| 类型 | 内容 |
|------|------|
| 正样本 | 只有唤醒词：**小T小T**（可带少量语速/音调变化） |
| 负样本 | 无固定词表：风扇声、键盘声、「打开风扇」、含糊说话等 |

## 三、TTS 播报女声（量产可选，v1 可跳过）

### 做什么

预录制真人女声 WAV，路由器 / daemon 播放「已打开风扇」等反馈。

**仅播放，不训练任何模型。** 预研阶段网页已用 `speechSynthesis` 女声，**现在可以不录**。

### 录制规范

| 项 | 要求 |
|----|------|
| 格式 | 16 kHz、mono、16-bit PCM WAV |
| 人声 | 同一人女声 |
| 环境 | 无背景音乐、无混响 |
| 时长 | 单句 < 3 秒 |

### 词表清单（首批）

#### `audio_clips/feedback/`（4 句）

| 文件名建议 | 念的句子 |
|------------|----------|
| `wake.wav` | 我在 |
| `unclear.wav` | 没听清，请再说一次 |
| `unknown.wav` | 无法理解指令 |
| `ok.wav` | 好的 |

#### `audio_clips/devices/`（3 句）

| 文件名建议 | 念的句子 |
|------------|----------|
| `fan_on.wav` | 已打开风扇 |
| `fan_off.wav` | 已关闭风扇 |
| `fan_level_2.wav` | 风扇已调到二档 |

> 其他档位（一档、三档…）可按同样句式各录一条，或量产前再补。

#### `audio_clips/router/`（量产 Phase 2，4 句）

| 文件名建议 | 念的句子 |
|------------|----------|
| `wifi_on.wav` | 已打开 WiFi |
| `wifi_off.wav` | 已关闭 WiFi |
| `guest_on.wav` | 已打开访客网络 |
| `guest_off.wav` | 已关闭访客网络 |

### 录完后

更新 `audio_clips/index.json`，把 key 指到对应 wav 路径。验证：

```bash
python3 -c "from voice_router_lite.tts.engine import TTSEngine; from voice_router_lite.config import DEFAULT_CONFIG; t=TTSEngine(DEFAULT_CONFIG.models, DEFAULT_CONFIG.audio); t.initialize(); t.speak_sentence('已打开风扇')"
```

## 四、快速对照：你现在要录什么？

| 要不要现在做 | 录什么 | 怎么做 |
|--------------|--------|--------|
| **要** | 开/关扇等指令 | 开 `SAVE_ASR_WAV`，正常演示，不用单独录文件 |
| **可选** | 小T小T 唤醒词 | 好麦录 20 正 + 10 负 → `kws_samples/` |
| **不用（v1）** | TTS 7～11 句 | 量产前再录 → `audio_clips/` |

```bash
# 指令采集（演示）

  VOICE_ROUTER_ENERGY_WAKE=1 python3 -m voice_router_lite web

python3 tools/eval_kws_samples.py --root kws_samples

```
