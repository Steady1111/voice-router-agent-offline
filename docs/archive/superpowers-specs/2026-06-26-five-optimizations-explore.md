## 1. 语音识别准确率

### 1.1 范围（做 / 不做）

| 做 | 不做 |
|----|------|
| 风扇开/关/档位（ESP32 预研） | 更换 ASR 为大模型（Paraformer/Whisper） |
| 16 类路由器意图 + 槽位（量产） | 自然语言自由对话 |
| 音频增益、采集窗、削波修复 | 云端 ASR 回退 |
| NLU 误识别样本再训 + 规则兜底 | 无限扩展关键词表（维护爆炸） |
| ASR 指令样本自动采集（`asr_debug`） | 重训 Zipformer ASR |
| KWS 双线：能量演示 + KWS 调参评估 | 重训 sherpa KWS 大模型（v1） |
| ASR 样本采集与 A/B 调参 | 在 128MB 路由器上常驻双 ASR 模型 |

### 1.2 唤醒双线研发（Q6）

**不是「预研能量 / 量产 KWS」二选一，而是 A/B 并行：**

| 线 | 环境 | 开关 | 目的 |
|----|------|------|------|
| **A 线** | ESP32 烂麦 | `ENERGY_WAKE=1` | 演示通风扇、自动采 `asr_debug` |
| **B 线** | Mac 好麦 / USB-I2S | 测时 `ENERGY_WAKE=0` | KWS「小T小T」命中率、量产验收 |

运行时逻辑：**每帧先 KWS，未命中再能量 fallback**（`ws_audio.py`）。两线共用同一服务，用 env 切换验收场景。

| 项 | A 线 | B 线 |
|----|------|------|
| 唤醒来源标记 | `energy_wake` | `kws` |
| 量产 | **关闭** | **仅此项** |
| 样本目录 | `asr_debug/`（指令） | `kws_samples/`（唤醒词） |

### 1.3 双模式边界（采集 / ASR / 兜底）

#### 预研模式（`python3 -m voice_router_lite web` + ESP32 WebSocket）

| 项 | 当前 | 目标 | 边界 |
|----|------|------|------|
| 唤醒 | KWS 每帧运行；A 线 + 能量 fallback | B 线单独调 KWS 阈值 | A 线 `ENERGY_WAKE=1`；B 线测时关 |
| 采集 | skip 0.25s，min 1.8s，静音 2s | 可调参，落盘对比表 | 不改固件协议 |
| ASR | 服务端 Zipformer，整段识别 | + 可选双路径（stream 结束后再 whole pass） | Mac 跑 ASR，不占 ESP32 算力 |
| 风扇兜底 | `command` 纠正 + `_fan_is_on` 状态机 | **仅风扇**，不泛化到路由器 | 风扇已开 + 短句胡话 → 关；未开 + 短句带风 → 开 |
| 路由器意图 | NLU 可走通，ubus 模拟 | **不考核误触发执行** | 预研重点验证风扇硬件链 |

#### 量产模式（`python3 -m voice_router_lite router` + ALSA）

| 项 | 边界 |
|----|------|
| 唤醒 | **仅 KWS「小T小T」+ VAD**，关闭能量唤醒 |
| 麦克风 | USB-I2S 直连路由器，不用 ESP32 传 PCM |
| 误执行 | **零容忍**：低置信 NLU / 非白名单意图 → 不执行 + 语音「没听清」 |
| 风扇控制 | 若仍用 ESP32 作执行端：经 WebSocket/ubus；若 GPIO 继电器：本地驱动 |
| ASR 内存 | 子进程识别完即退出；与 KWS 分时互斥 |

### 1.4 置信度与拒绝策略

```
唤醒成功
  → 采集指令音频（最长 8s，静音 2s 结束）
  → ASR 出文本
  → repair → NLU
  → 若 intent 为 router_* 且 confidence < 0.5 → 拒绝执行
  → 若 voice_wake 且文本长度 ≤8 且非路由器关键词 → 仅风扇场景允许状态机兜底
  → 执行 / 播报
```

| 场景 | 阈值 | 失败反馈 |
|------|------|----------|
| NLU 路由器意图 | confidence ≥ 0.5 | 「没听清，请再说一次」 |
| NLU 风扇意图（预研兜底后） | confidence ≥ 0.65 或 keyword 命中 | 同上 |
| ASR 空文本 + 有能量 | 预研：按风扇状态猜测；量产：**不猜测** | 量产必须追问 |
| 执行成功 | — | 「已打开风扇」等规范句 |

### 1.5 风扇 vs 路由器：兜底边界（关键）

**仅下列条件允许「非字面」纠正为风扇指令：**

1. `voice_wake=True`（已唤醒，非网页文本框）
2. `device_type` 上下文为风扇预研，或 `fan_is_on` 状态已知
3. 文本 **不含** 路由器关键词（路由、WiFi、密码、重启、防火墙…）
4. 文本长度 ≤ 8 字，或命中 `_FAN_*_MISHEARD` 表

**禁止：**

- 把「本币一份」类胡话纠正为 `router_reboot`（已修复方向：纠正为关风扇或拒绝）
- 网页文本输入走状态机兜底（`voice_wake=False`）
- 用风扇状态机覆盖明确的路由器指令（含关键词则不兜底）

### 1.6 数据采集边界

**三条录音线（勿混淆）：**

| 线 | 目录 | 用途 | 训练模型？ | v1 优先级 |
|----|------|------|------------|-----------|
| TTS 播放 | `audio_clips/` | 播报听感 | 否 | 低，可延后 |
| 指令采集 | `asr_debug/` | 误识别分析 → NLU/规则 | 间接（文本） | **高** |
| 唤醒样本 | `kws_samples/` | KWS 命中率评估 | 否（调阈） | 中，B 线 |

| 环境变量 | 作用 | 默认 |
|----------|------|------|
| `VOICE_ROUTER_SAVE_ASR_WAV` | 保存每次指令 WAV + asr/command 元数据 | 关 |
| `VOICE_ROUTER_ASR_DEBUG_DIR` | 输出目录 | `./asr_debug/` |

采集字段：`timestamp`, `raw_asr`, `repaired`, `command`, `intent`, `success`, `wake_source`, `peak`, `duration_sec`

**用户参与：** 正常演示开/关扇即可（用着采），**不必坐着录 30 句 TTS**。

**隐私**：仅本地存储，不上传；量产默认关闭。

### 1.7 验收边界

| 环境 | 用例集 | 通过线 |
|------|--------|--------|
| ESP32 预研 | 开风扇/关风扇各 10 次 | ≥ 8/10 正确执行 |
| ESP32 预研 | 5 次环境噪声（风扇转着） | ≥ 3/5 正确 |
| Mac 麦克风 | 20 条路由器核心句 | ≥ 16/20 意图+槽位正确 |
| 误执行 | 10 条无关胡话 | 0 次误执行危险操作（重启等） |

## 2. 设备状态面板（风扇 + 路由器）

### 2.1 范围

| 展示 | 不展示 |
|------|--------|
| 风扇：连接、开关、档位、RPM、最后指令、最后 ACK | LED、继电器 Mock 设备 |
| 路由器：WAN、下联设备数、语音服务状态、内存/CPU | 完整 Luci 复刻 |
| ESP32：WebSocket 连接 IP、在线时长 | 每台下联设备详情列表（v1 不做） |

### 2.2 页面角色

| 视图 | 入口 | 受众 |
|------|------|------|
| **用户视图**（默认） | `/` | 最终用户、主管演示 |
| **调试视图** | `/?debug=1` | 开发、预研监控 |

用户视图右侧 **仅两块卡片**：`路由器` + `风扇`。  
性能监控 7 卡 **仅在 debug=1 显示**。

### 2.3 API 边界

#### `GET /api/router-status`（新增）

| 字段 | 预研（Mac） | 量产（OpenWrt） |
|------|-------------|-----------------|
| `wan_up` | mock `true` | ubus / `network.interface.wan` |
| `lan_clients` | mock 或 `0` | DHCP 租约计数 / ubus |
| `voice_daemon` | `web` / `running` | `router` 进程存活 |
| `ram_used_mb` | 来自 monitor | `/proc` 或 ubus |
| `ram_total_mb` | `128` | 实际 |
| `cpu_pct` | 来自 monitor | 可选 |

#### `GET /api/esp32-status`（已有，扩展）

| 字段 | 来源 |
|------|------|
| `connected` | bridge.session_count > 0 |
| `sessions[].host` | ESP32 IP |
| `fan.on` / `fan.level` | 服务端 `_fan_is_on` + ACK 同步 |
| `last_ack_at` | ESP32 `device_state` 事件时间戳 |
| `last_command` | 最近一次 `command` 字段 |

#### `GET /api/devices`（收缩）

- **仅返回** `fan` + 虚拟 `router` 条目
- 移除 `led`、`relay` 默认注册（或 `debug=1` 才返回）

### 2.4 刷新策略

| 数据 | 方式 | 间隔 |
|------|------|------|
| 风扇 ACK、对话 | WebSocket 推送 | 实时 |
| 路由器 WAN、客户端数 | HTTP 轮询 | 10s |
| 内存 CPU | HTTP 轮询 | 2s（仅 debug） |

### 2.5 边界 case

| case | 行为 |
|------|------|
| ESP32 断线 | 风扇卡显示「离线」，灰点；不显示过时 RPM |
| 风扇 ACK 丢失 | 显示「指令已发，待确认」；5s 后提示重试 |
| 路由器 ubus 不可用 | `lan_clients: null`，显示「—」；不 fake 数字 |
| 仅 Web 无 ESP32 | 风扇卡「未连接」；网页文字控扇仍可用（服务端状态） |

## 3. 语音播报反馈

### 3.1 双端策略（v1 修订）

| 端 | v1（现在） | 量产（可选） | 不做 |
|----|------------|--------------|------|
| **预研网页** | speechSynthesis **女声** + 蜂鸣 | 有 WAV 则播 WAV | 男声默认朗读 |
| **路由器量产** | — | 预录女声 WAV → I2S | 依赖浏览器 TTS |
| **ESP32 固件** | RGB + 数码管 | 同左 | 解析 MP3 流（v1 不做） |

### 3.2 反馈矩阵（灯 + 声）

| 事件 | RGB（ESP32） | 语音（路由器/网页） | 蜂鸣 |
|------|--------------|---------------------|------|
| 唤醒 | 红 + 倒计时 | 「我在」 | 可选短唤醒音 |
| 正在听 | 红保持 | 静音 | 无 |
| 执行成功 | 绿 1.5s | 「已打开风扇」等 **command 对应句** | 无 |
| 没听清 | 黄闪 2s | 「没听清，请再说一次」 | 无 |
| 执行失败 | 红闪 | 「无法理解指令」 | error_beep |
| 风扇已开 | 蓝闪 1.5s → 绿 | 无（避免盖过回复） | 无 |

**原则：** 有完整语音句时 **不播蜂鸣**；蜂鸣仅用于无 TTS 素材或极端失败。

### 3.3 预录制素材边界（量产可选，v1 可跳过）

> `audio_clips` 仅播放，不训练模型。

| 分类 | 句数上限 | 磁盘 |
|------|----------|------|
| feedback | 8 | ~500KB |
| devices | 5 | ~300KB |
| router 高频 | 12 | ~800KB |
| **合计** | ≤ 30 句 | < 3MB（预算 5MB） |

**录制要求：** 同一人女声、16kHz mono 16bit WAV、无背景音乐。

**v1 不录制：** 数字读法（一到十）、长句路由器回复；用拼接：「已打开」+「风扇」。

### 3.4 网页 speechSynthesis 边界（预研）

| 项 | 规则 |
|----|------|
| 声音 | 强制女声：排除 Kangkang / Yunxi / Li-mu / Google 普通话（中国大陆）男声 |
| 优选 | Xiaoxiao、Ting-Ting、Sinji、Huihui 等 |
| 语速 | rate 0.95–1.0 |
| 与 WAV | 若服务端已发完整句 WAV，**网页不重复 speechSynthesis** |
| 与蜂鸣 | 朗读中不播 error_beep |

### 3.5 播报文本来源

| 字段 | 用途 |
|------|------|
| `command` | 对话区展示（纠正后） |
| `reply` | TTS 播报内容（与执行结果一致） |

**禁止** 播报 raw ASR（如「风水」）；必须播报 `reply`（如「已关闭风扇」）。

## 4. 前端页面布局

### 4.1 信息架构

```
顶栏：标题 | 路由器状态点 | 风扇状态点 | 唤醒状态点
主栏（左 60%）：对话区（主）
侧栏（右 40%）：路由器卡 + 风扇卡
底栏：文字输入 + 按住说话（预研）
折叠区（debug=1）：性能监控 7 卡
```

### 4.2 移除 / 保留

| 移除或默认隐藏 | 保留 |
|----------------|------|
| Mock LED/继电器列表 | 对话 + 纠正展示 |
| 唤醒大卡片（与顶栏重复） | 文本调试输入 |

### 4.3 响应式边界

| 宽度 | 布局 |
|------|------|
| ≥ 900px | 左右双栏 |
| < 900px | 单栏；设备状态折叠为底部抽屉 |

### 4.4 访问边界

## 5. 内存压缩

### 5.1 预算硬线（128MB 路由器）

| 阶段 | RSS 上限 | 动作若超 |
|------|----------|----------|
| 待机 | ≤ 75 MB | 告警日志 |
| 唤醒峰值 | ≤ 88 MB | 拒绝加载 ASR，播报「请稍后再试」 |
| 识别后 3s | ≤ 76 MB | ASR 子进程必须已退出 |

### 5.2 策略开关（量产 `voice-router.json`）

| 配置 | 预研 web | 量产 router |
|------|----------|-------------|
| `model_serial_exclusive` | 可选关 | **必须开** |
| `asr_subprocess` | 可选关 | **必须开** |
| `prefer_int8_nlu` | 可选 | **必须开**（INT8 文件存在时） |
| `enable_tts_feedback` | 开 | 开 |
| FastAPI Web | 开 | 开（轻量） |
| ASR 常驻 web 进程 | 关（ESP32 流式） | 不适用 |

### 5.3 INT8 边界

| 项 | 规则 |
|----|------|
| 启用条件 | `intent_model.int8.onnx` 存在且自检 ≥ 99% 意图准确率 |
| 回退 | INT8 缺失或精度不达标 → fp32（+7MB，记录告警） |
| 训练 | 导出脚本已有；需补精度回归用例 26→扩展 50 |

### 5.4 不在 v1 做的优化

- KWS 换更小模型（需重新验唤醒率）
- 音频缓冲缩到 < 1s（可能影响长句 ASR）
- 砍掉 Web 服务省内存（产品要求保留）

### 5.5 度量

| 指标 | 采集方式 |
|------|----------|
| RSS 分阶段 | daemon 启动 / KWS / ASR 子进程 / 退出后 |
| 网页展示 | `/api/monitor` 已有，debug 视图 |
| 72h 稳定性 | QEMU MIPS 或实机；泄漏 > 5MB 失败 |

## 6. 实施阶段与依赖

```
Phase 1（可并行）
  ├─ 1A  指令采集 asr_debug（优先，用着采）
  ├─ 1E  KWS B 线样本 + 命中率评估
  ├─ 5A  INT8 导出 + 精度回归
  ├─ 2A  router-status API 草案
  └─ 1B  TTS WAV（可选延后）

Phase 2（依赖 Phase 1 部分产出）
  ├─ 1B  NLU 误识别样本再训（需 1A 样本）
  ├─ 2B  + 4B  前端用户视图 + debug 开关
  └─ 3B  路由器 DAC 播放链路（1B 非阻塞）

Phase 3（上板）
  ├─ 1C  量产仅 KWS（关能量唤醒）
  ├─ 5B  QEMU 72h
  └─ 全量验收
```

**Phase 1 不改动：** 固件引脚、WebSocket 协议、NLU 意图集合。
