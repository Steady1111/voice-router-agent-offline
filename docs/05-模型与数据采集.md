## 一、训练边界

| 模型 | 是否自训 | 说明 |
|------|----------|------|
| 唤醒词 KWS | 一般不自训 | 用 sherpa 预训练 + 关键词配置；样本用于评估调参 |
| ASR | **不自训** | 用 Zipformer 预训练（zh 14M mobile） |
| 指令 NLU | **自训** | 模板生成语料 → CNN+LSTM → ONNX / INT8 |

ASR 从零训练成本与数据量不现实；本项目只训 NLU，KWS 以评估与阈值为主。

---

## 二、方案摘要

### 唤醒词

- 引擎：sherpa-onnx KWS（约 3.3MB）
- 唤醒词示例：「小T小T」
- 量产主路径；ESP32 预研演示可用音量门限保底

### ASR

- sherpa-onnx Zipformer 中文约 25MB
- 量产：子进程按需加载；可选 C++ worker
- ESP32 麦误识别高：风扇靠关键词兜底；路由意图预研走文本/浏览器麦

### NLU

- 字符级 CNN+LSTM，意图 + BIO 槽位
- 约 16 类意图（路由核心 + 家居扩展）
- 训练：`python3 -m voice_router_lite.nlu.train_nlu`
- 指标量级（历史记录）：意图约 99.8%，槽位约 99.4%；fp32 ~11MB，INT8 ~2.8MB
- 运行时另有路由器朗读 ASR 纠错表（服务端），不进 ESP32

### TTS

- 预录 WAV 拼接，零运行时神经网络内存
- v1 可用网页女声 / 蜂鸣，真人 WAV 可延后

### 意图表示例

| 类型 | 意图例 | 说法例 |
|------|--------|--------|
| 路由 | reboot / wifi / query / qos / security … | 重启路由器、WiFi 密码、限速… |
| 家居 | device_control / adjust / query / timer / scene / help | 开风扇、调大、定时… |

## 三、三条录音线（勿混淆）

| 线 | 目录 | 是否训模型 | v1 优先级 |
|----|------|------------|-----------|
| 指令采集 | `asr_debug/` | 间接服务 NLU/规则 | **高** |

## 四、指令采集（优先）

演示时正常说指令，自动落盘 WAV + 元数据；**不重训 ASR**。

```bash
VOICE_ROUTER_SAVE_ASR_WAV=1 \
VOICE_ROUTER_ASR_DEBUG_DIR=./asr_debug \
python3 -m voice_router_lite web

python3 tools/collect_asr_samples.py --dir ./asr_debug
python3 tools/build_misheard_training.py --dir ./asr_debug   # 样本够后
```

建议覆盖：开/关扇、调档、风扇运转噪声下关扇、闲聊负样本；路由指令可选。

| 阶段 | 数量 |
|------|------|
| 可分析 | ≥20 |
| 再训参考 | ≥50 |

## 五、KWS 样本与评估

- 格式：16kHz mono 16-bit WAV
- 设备：Mac/USB 好麦（不用 ESP32 烂麦当验收麦）
- 正样本约 20 条「小T小T」；负样本约 10 条
- 通过线参考：正 ≥14/20，负误唤醒 ≤2/10

```bash
VOICE_ROUTER_ENERGY_WAKE=0 python3 -m voice_router_lite web
python3 tools/eval_kws_samples.py --root kws_samples
```

目录约定见 `kws_samples/README.md`。

```bash
python3 tools/export_nlu_int8.py

```

量产配置倾向 `prefer_int8_nlu: true`。部署步骤见 [03-部署手册](./03-部署手册.md)。
