## 一、预研启动（Mac + Web）

```bash
cd /path/to/voice-router-agent-offline

# 模型（首次）
bash download_models.sh
python3 -m voice_router_lite.nlu.train_nlu   # 如需生成/更新 NLU

# 启动控制台
VOICE_ROUTER_WEB_HOST=0.0.0.0 \
VOICE_ROUTER_WEB_PORT=28080 \
python3 -m voice_router_lite web
```

浏览器打开 `http://localhost:28080/`（演示加 `?demo=1`，调试加 `?debug=1`）。

演示流程见 [02-演示脚本](./02-演示脚本.md)。

## 二、环境变量速查

| 变量 | 用途 | 备注 |
|------|------|------|
| `VOICE_ROUTER_WEB_HOST` / `PORT` | Web 监听 | 默认本机 28080 |
| `VOICE_ROUTER_SAVE_ASR_WAV` | 指令 WAV 落盘 | 采集见 [05](./05-模型与数据采集.md) |
| `VOICE_ROUTER_ASR_DEBUG_DIR` | 落盘目录 | 如 `./asr_debug` |
| `VOICE_ROUTER_ENERGY_WAKE` | 浏览器/旧能量兜底 | ESP32 方案 1 主路径不依赖 |
| `VOICE_ROUTER_VOLUME_WAKE_PEAK` / `RMS` | 音量唤醒门限 | 方案 1 |
| `VOICE_ROUTER_COLLECT_SEC` / `SILENCE_SEC` | 单次采集窗 | 方案 1 |
| `VOICE_ROUTER_WAKE_COOLDOWN_SEC` | 唤醒冷却 | 默认约 3s |
| `VOICE_ROUTER_SKIP_SEC` / `MIN_COMMAND_SEC` | 采集窗微调 | 指令样本 |
| `VOICE_ROUTER_ASR_WORKER` | C++ ASR 二进制路径 | 量产推荐 |
| `VOICE_ROUTER_MEMORY_MODE` | `router_sim` / `live_rss` / `daemon_snapshot` | 控制台内存展示 |

## 三、OpenWrt 安装

将工程安装到路由器 `/opt/voice_router/`：

```bash
# 开发机
bash download_models.sh
python3 -m voice_router_lite.nlu.train_nlu
tar czf voice_router.tar.gz voice_router_lite/ models/ audio_clips/ deploy/

# 路由器
scp voice_router.tar.gz root@<router-ip>:/tmp/
ssh root@<router-ip>
cd /opt && mkdir -p voice_router && tar xzf /tmp/voice_router.tar.gz -C voice_router
pip3 install -e /opt/voice_router   # 或预装 wheel

cp /opt/voice_router/deploy/openwrt/voice-router.init /etc/init.d/voice-router
cp /opt/voice_router/deploy/openwrt/voice-router.json /opt/voice_router/deploy/openwrt/
/etc/init.d/voice-router enable
/etc/init.d/voice-router start
```

配置与脚本以 `deploy/openwrt/` 为准。

## 四、双进程（Web + Daemon）

| 服务 | init 脚本 | 说明 |
|------|-----------|------|
| `voice-routerd` | `voice-routerd.init` | KWS/ASR/NLU/TTS，量产语音 |
| `voice-router-web` | `voice-router-web.init` | FastAPI `:28080`，无 ALSA |

```
USB-I2S → ALSA → voice-routerd
                    ├── KWS 常驻
                    ├── 唤醒后卸 KWS → ASR 子进程 → 退出
                    ├── NLU INT8 常驻
                    └── ubus → 网络 / 系统 / GPIO
```

守护进程可打 RSS 阶段日志：`daemon_start` / `after_initialize` / `after_kws_listen` / `after_shutdown`。

## 五、Native ASR Worker

交叉编译 C++ worker 可去掉 Python ASR 子进程约 30MB 开销。

```bash
# 见 native/README.md
bash native/build-mips-openwrt.sh
scp native/bin/voice-router-asr-worker-mips root@router:/opt/voice_router/bin/voice-router-asr-worker

export VOICE_ROUTER_ASR_WORKER=/opt/voice_router/bin/voice-router-asr-worker
```

未设置时回退 Python `asr_worker`。

| 阶段 | Python ASR | C++ worker |
|------|------------|------------|
| 待机 | ~72MB | ~72MB |
| 峰值 | ~89MB | ~65MB（估算） |

## 六、控制台内存对照

| 环境 | 模式 | 行为 |
|------|------|------|
| Mac 预研 | `router_sim` | 待机↔峰值状态机模拟 |
| OpenWrt 真机 | `live_rss` | `/proc/meminfo` + 进程 RSS |
| Web+daemon | `daemon_snapshot` | 读 daemon 写入的内存快照文件 |

ASR 起止会驱动进度条在预算区间跳动。

## 七、健康检查与常见故障

```bash
# 路由器
logread -f | grep voice
python3 -m voice_router_lite router --text "打开风扇"

# 开发机
python3 -m pytest tests/ -q
curl -s http://localhost:28080/health
curl -s http://localhost:28080/api/router-status
```

| 现象 | 处理 |
|------|------|
| 28080 占用 | `kill $(lsof -t -i :28080)` |
| 无 ASR 模型 | 跑 `download_models.sh`，确认 zh 14M mobile |
| 网页麦失败 | 仅 localhost + Chrome/Safari |
| ESP32 不上线 | 查固件 WiFi / HUB 地址，见 [04](./04-开发与硬件手册.md) |
| 风扇一转就复位 | 电机独立供电并共地 |
